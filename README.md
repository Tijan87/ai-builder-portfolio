# Lukasz Rodzen - AI Product Builder

A concise, standalone portfolio based on the original case-study site. The original repository and pages remain separate.

## Files

- `index.html`: portfolio content and accessible HTML structure.
- `styles.css`: responsive styling adapted from the original dark palette and typography.
- `script.js`: product-video switching, captions and load-error handling.
- `assets/Lukasz-Rodzen-CV.pdf`: current one-page CV.

No build tools or dependencies are required. Serve this directory with a static HTTP server to preview it. GitHub Pages can publish directly from the root of `main`.

## Media and evidence

The videos and poster images use the same source assets as the original case-study site. The overview uses its original 4K file. The full walkthrough uses the original 4K media-hosted file at viewport widths of 900px and above, and the original 1080p GitHub-hosted version on smaller screens. Its direct link always opens the 4K version. No videos are re-encoded. The videos retain their original recorded content and branding; the page uses the neutral product description.

The optional evidence section links to the original detailed case studies. Their measurements retain their original dates and definitions.

## Updating

Edit the HTML copy, update the CV file when needed, and push to `main`. Change both `index.html` and `script.js` when updating the overview media. Keep funding described as development funding in exchange for data access, separate from trading capital.
